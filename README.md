## About

In this module, you'll learn how factory design patterns reduce class and object complexity and learn about how to implement them in Java applications.

## Content

| Lesson | Est. Delivery Time | Skills |
| ------ |:------------------:| ------ |
| [Setup](./setup/README.md)                                                       |      10 min | Set up the development environment.                                                                  |
| [Factory Method Pattern](./factory-method-pattern/README.md)                     |      30 min | Describe factory design pattern and identify appropriate scenarios where it can be applied.          |
| [Factory Method Pattern in Action](./factory-method-pattern-in-action/README.md) |      20 min | Implement factory design pattern in Java.                                                            |
| [Abstract Factory Pattern](./abstract-factory-pattern/README.md)                 |      20 min | Describe abstract factory design pattern and identify appropriate scenarios where it can be applied. |
| [Abstract Factory Pattern in Action](./abstract-factory-pattern-in-action/)      |      20 min | Implement abstract factory design pattern in Java.                                                   |
| **Total content**                                                                | 1 hr 40 min |                                                                                                      |
